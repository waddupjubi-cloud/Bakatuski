Put global music files here.

Expected default paths from `assets/data/audio.json`:

- `themes/dark-theme.mp3`
- `themes/light-theme.mp3`
- `themes/bamboo-theme.mp3`
- `players/{member-slug}.mp3`

Examples:

- `players/biju.mp3`
- `players/salina.mp3`
- `players/aashray.mp3`

You can change names, add playlists, or add remote URLs in `assets/data/audio.json`.
